Platform

Everything between your code and the model

One middleware layer for caching, routing, cost control, and quality assurance — instrumented end to end.

Semantic Cache Engine

Embedding-based matching returns cached completions for paraphrased prompts. Tune similarity thresholds per prompt, set TTLs, and invalidate by tag or prompt version.

Multi-Model Fallbacks & Routing

Declare ordered fallback chains and route by cost, latency, or task type. Automatic retries with jittered backoff when a provider returns 429 or 5xx.

Token Budget Guardrails

Enforce per-request, per-user, and per-project token ceilings. Hard stops or soft alerts prevent runaway loops and surprise invoices.

Edge Proxy Latency Optimization

Regional edge nodes terminate TLS close to your servers, keep upstream connections warm, and reuse HTTP/2 streams to shave off connection overhead.

Real-time Observability & Traces

Per-request traces with latency breakdowns, token counts, cache decisions, and cost. Export spans via OpenTelemetry to the tools you already run.

Automated Prompt Regression Testing

Replay golden datasets against every prompt version in CI. Score outputs with assertions or model graders and block merges that degrade quality.

Architecture

A thin, fast layer on the hot path

Requests hit the nearest edge node, are normalized and embedded, then checked against a vector-indexed cache. Misses are routed to your chosen provider, streamed back to the client, and written to cache asynchronously — so cache population never adds to response time.

  • Streaming passthrough with SSE and chunked responses
  • Per-tenant cache namespaces with encryption at rest
  • Stateless nodes, horizontally scaled across regions

Frequently asked questions

Cached payloads are encrypted with AES-256 at rest and TLS 1.3 in transit, and isolated in per-tenant namespaces. You control retention with per-prompt TTLs, can mark prompts as never-cache, and can enable PII redaction before embedding. Provider API keys are stored encrypted and never written to traces. You can purge any namespace or tag at any time via the API.

Cache hits are designed to return in under 10ms at the edge, measured server-side from request receipt to first byte. Cache misses add a small proxy overhead on top of provider latency. Every response includes a meta.latency breakdown, and our benchmark harness is documented so you can reproduce results against your own traffic.

First-party SDKs are available for Node.js (@devprompt/sdk, TypeScript-first) and Python (devprompt, sync and async). Express and Next.js middleware adapters are included. Anthropic Claude is supported natively, and any provider with an OpenAI-compatible endpoint can be added as a route.

You pay DevPrompt only for requests processed through the middleware, based on your plan's included volume plus metered overage. Provider token charges are billed by your provider directly using your own keys, so there is no markup on model usage. Cached hits never consume provider tokens. You can cancel or change plans at any time.
